VidKeys is a website currently in development, created by aspiring software developer Devin Coombs.

The software will include video chatting and image/video sharing materials, similar to zoom and combining that with chat style messaging that will allow friends/families to connect via video call.

During video calls there will be some preset video games that you can play together, simple family-friendly games that can be enjoyed by anybody. In a future version, I would like to implement a way for the user to create their own games/apps.

The users will be able to create accounts, add friends, create private chat rooms and video call rooms between one or multiple people at a time.
